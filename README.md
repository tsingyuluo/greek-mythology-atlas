# 希腊神话志 · 中文互动知识图谱

一个无需构建、可直接在浏览器打开的中文希腊神话探索网站，连接人物、故事、艺术与古典原典。

## 在线访问

发布后可通过 GitHub Pages 直接浏览；仓库包含运行所需的全部本地图片与前端代码。

## 内容

- 44 位神祇、英雄、王族与怪物人物档案
- 20 条故事线与分章叙事
- 可展开直接关系与第二层关联的人物关系图
- 6 个艺术专题与 14 条古典原典
- 全站本地图片资源，无外部图片依赖

## 本地运行

直接用浏览器打开 `index.html` 即可。推荐使用 Chrome、Safari 或 Edge 的较新版本。
